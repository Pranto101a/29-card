# ২৯ তাস গেম (বট + পাস অ্যান্ড প্লে + অনলাইন)

## ফাইল
- `public/index.html` — পুরো গেম (ক্লায়েন্ট)
- `server.js` — Node.js সার্ভার (সাইট দেখায় + অনলাইন রুম চালায়)
- `package.json`, `render.yaml` — Render-এর জন্য

## লোকালে চালানো
```
npm install
npm start
```
তারপর ব্রাউজারে http://localhost:3000 খুলুন।

## GitHub-এ আপলোড
1. github.com এ নতুন repository বানান (যেমন `game29`)।
2. "uploading an existing file" চেপে এই ফোল্ডারের সব ফাইল (`public` ফোল্ডারসহ) আপলোড করে Commit করুন।

## Render-এ ডিপ্লয়
1. render.com এ লগইন করে **New → Web Service** চাপুন, GitHub repo সিলেক্ট করুন।
2. Runtime: **Node**, Build Command: `npm install`, Start Command: `npm start`, Plan: Free।
3. Deploy শেষ হলে পাওয়া লিংকটাই আপনার গেম। অনলাইন মোডে "রুম খুলুন" → ৪ অক্ষরের কোড বন্ধুদের দিন।

## নোট
- অনলাইনে পেজ রিফ্রেশ বা নেট চলে গেলে আবার ঢুকলে "↩ আগের রুমে ফিরুন" বোতামে খেলা চালু থাকে (খেলোয়াড়ের জন্য ৪৫ সেকেন্ড, হোস্টের জন্য ৩ মিনিট সময়)।
- Render ফ্রি প্ল্যানে ১৫ মিনিট কেউ না ঢুকলে সার্ভার ঘুমায়; পরের বার খুলতে ~৩০ সেকেন্ড লাগে।
- অনলাইন মোডে হোস্টের ব্রাউজার খেলা চালায়, তাই হোস্ট ট্যাব বন্ধ করলে খেলা শেষ হয়ে যায়।

## অফলাইন
একবার ইন্টারনেটে গেমটা খুললেই (`sw.js` দিয়ে) পরে নেট ছাড়াই চলে। ফোনে ব্রাউজার মেনু থেকে "Add to Home Screen" দিলে অ্যাপের মতো খোলে। `index.html` একা ফাইল হিসেবেও অফলাইনে খোলা যায়।

## নোট
- কার্ডের ছবি `public/cards/` এ (`AS.webp`, `10H.webp`, `JD.webp` ... S=♠ H=♥ D=♦ C=♣, `BACK.webp` = পিঠ)। ছবি না পেলে গেম কোডে আঁকা কার্ড দেখায়।
- এই ভার্সনে শুধু বটের সাথে সিঙ্গেল প্লেয়ার চলে।
- হোমে তিনটা অপশন: Single Player, Friends & Bots (এক ফোনে রিয়েল প্লেয়ার + বট, নাম দেওয়া যায়), Online (শীঘ্রই)। ⚙ থেকে "Play the game your way" রুলস সেটিংস।
